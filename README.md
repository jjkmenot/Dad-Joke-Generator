# Dad-Joke-Generator
The Dad Joke Generator is a simple fun tool that generates random dad jokes. Whether you’re in need of a laugh or just want to annoy someone with a classic dad joke, this tool has you covered! It pulls from a collection of dad jokes and delivers them in a text format.
